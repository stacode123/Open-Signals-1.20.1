# Open Signals 1.20.1 Port - Refactor Guide

This document outlines the remaining changes needed to complete the port to Minecraft 1.20.1.

## Status
✅ **COMPLETED**: All minor API breaking changes
- Registry API: `Registry.BLOCK` → `BuiltInRegistries.BLOCK`
- ModelData API: `EmptyModelData.INSTANCE` → `ModelData.EMPTY`  
- Build configuration updated (Gradle 8.1, ForgeGradle 6.0, MC 1.20.1, Forge 47.4.0)

❌ **TODO**: Major architectural changes required

## Required Changes

### 1. Registration System Refactor (MAJOR)

**Problem**: Forge 1.20.1 removed `RegistryEvent` in favor of `DeferredRegister`

**Current Pattern** (src/main/java/com/troblecodings/signals/init/OSBlocks.java):
```java
@SubscribeEvent
public static void registerBlock(final RegistryEvent.Register<Block> event) {
    final IForgeRegistry<Block> registry = event.getRegistry();
    BLOCKS_TO_REGISTER.forEach(registry::register);
}
```

**Required Pattern** for 1.20.1:
```java
public class OSBlocks {
    public static final DeferredRegister<Block> BLOCKS = 
        DeferredRegister.create(ForgeRegistries.BLOCKS, OpenSignalsMain.MODID);
        
    public static final RegistryObject<Block> POST = 
        BLOCKS.register("post", () -> new Post(/* params */));
        
    // In OpenSignalsMain constructor:
    // BLOCKS.register(eventBus);
}
```

**Files to Update**:
- `src/main/java/com/troblecodings/signals/init/OSBlocks.java`
- `src/main/java/com/troblecodings/signals/init/OSItems.java`  
- `src/main/java/com/troblecodings/signals/init/OSSounds.java`
- `src/main/java/com/troblecodings/signals/OpenSignalsMain.java` (registration calls)

### 2. Creative Tab System Refactor (MEDIUM)

**Problem**: Creative tab system completely overhauled in 1.20.1

**Current Pattern** (src/main/java/com/troblecodings/signals/init/OSTabs.java):
```java
public static final CreativeModeTab TAB = new CreativeModeTab("Open Signals") {
    @Override
    public ItemStack makeIcon() {
        return new ItemStack(OSItems.LINKING_TOOL);
    }
};
```

**Required Pattern** for 1.20.1:
```java
public class OSTabs {
    public static final DeferredRegister<CreativeModeTab> CREATIVE_MODE_TABS = 
        DeferredRegister.create(Registries.CREATIVE_MODE_TAB, OpenSignalsMain.MODID);

    public static final RegistryObject<CreativeModeTab> TAB = CREATIVE_MODE_TABS.register("open_signals", 
        () -> CreativeModeTab.builder()
            .title(Component.translatable("itemGroup.open_signals"))
            .icon(() -> new ItemStack(OSItems.LINKING_TOOL.get()))
            .displayItems((parameters, output) -> {
                // Add items to creative tab
                OSBlocks.BLOCKS.getEntries().stream()
                    .map(RegistryObject::get)
                    .forEach(block -> output.accept(block));
            })
            .build());
}
```

### 3. Update References

After implementing DeferredRegister, update all references:
- Change `OSBlocks.POST` to `OSBlocks.POST.get()`
- Change `OSItems.LINKING_TOOL` to `OSItems.LINKING_TOOL.get()`
- Update item registration to use block registry objects

### 4. Build Test

Once these changes are made, the mod should build successfully with:
```bash
./gradlew build --no-daemon
```
